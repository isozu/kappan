# 灯台守の最後の夜

{岬|みさき}の{突端|とったん}に、白い{灯台|とうだい}がひとつ立っている。
百年ものあいだ、その{灯|ひ}は海を{渡|わた}る船を見守ってきた。

けれど自動化の{波|なみ}には{抗|あらが}えず、灯台守という{仕事|しごと}は、いまや
[消えゆく{灯|ともしび}]{.kenten}になろうとしていた。

これは、ひとりの灯台守が{迎|むか}えた、最後の{当直|とうちょく}の夜の話である――
[すべては書き下ろしのオリジナルであり、登場する人物も土地も架空のものである]{.kenten}。
