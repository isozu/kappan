# 第8章 各ストアへの入稿

EPUBCheck を通過した EPUB は、概ね主要な電子書籍ストアへ直接入稿できる状態にある。本章では、ストアごとの特徴と注意点をまとめる。各ストア向けの最適化プラグインは今後の予定であるため、本章は参考情報として位置付ける。

## 8.1 各ストアの概観

| ストア        | EPUB 直接受理 | 内部形式        | 縦書き対応 | 固定レイアウト |
| ------------- | :-----------: | --------------- | :--------: | :------------: |
| Apple Books   |       ✓       | EPUB そのまま   |     ✓      |       ✓        |
| Kindle（KDP） |       ✓       | KFX/AZW3 へ変換 |     ✓      |       ✓        |
| Kobo          |       ✓       | KEPUB（任意）   |     ⚠      |       ✓        |
| honto         |       ✓       | EPUB そのまま   |     ✓      |       ✓        |
| BookLive      |       ✓       | EPUB そのまま   |     ✓      |       ✓        |

凡例：✓ 完全対応／⚠ 部分対応

## 8.2 Apple Books

Apple Books は EPUB 3.3 への追従が最も進んでおり、Kappan の出力は追加調整なしで表示される。

入稿には Apple ID と「iTunes Connect」のセラーアカウントが必要となる。書籍は iTunes Producer または Books Connect 経由でアップロードする。

- メディアオーバーレイ（音声同期）：完全対応。Kappan の基本実装は今後の予定
- iOS の Dynamic Type：本文の `rem`/`em` 指定により自動的に適合
- リーディングモード（白・セピア・夜間）：Mono テーマは三モードすべてで読みやすく設計されている

## 8.3 Amazon Kindle（KDP）

KDP は EPUB をアップロードすると内部で KFX または AZW3 に変換する。この変換時に対応していない CSS プロパティが存在するため、注意が必要である。

### 変換時に破綻しやすい CSS

- `position: fixed` / `position: absolute`
- `transform`、`filter`、`backdrop-filter`（固定レイアウト書籍を除く）
- 未定義 fallback の CSS カスタムプロパティ
- `@supports` クエリ（解釈が不安定）

Mono テーマはこれらを意図的に使わない設計のため、変換後も問題なく表示される。今後提供予定の `@kappan/plugin-kdp-lint` バリデータが、書籍著者が独自 CSS を加える際にも違反を検出するよう支援する。

### 表紙画像

KDP の表紙画像要件（2025 年時点）：

- 推奨解像度：2560 × 1600 ピクセル
- アスペクト比：1.6:1（高さ : 幅）
- フォーマット：JPEG または TIFF
- ファイルサイズ：50 MB 以下
- 色空間：sRGB

表紙画像の検証プラグインは今後の予定。当面は手動で確認するか、`@kappan/plugin-cover-validate` の提供を待つ。

### なか見！検索

KDP の「なか見！検索」では書籍冒頭の 10% 程度がプレビューされる。この領域のレイアウト品質が購入判断に直結するため、最初の章は丁寧に組むことを推奨する。

## 8.4 Kobo

Kobo は EPUB 3 への準拠が高いが、独自の KEPUB 拡張への変換も可能である。KEPUB に変換すると、Kobo 端末上でハイライト同期や読書時間計測などの拡張機能が有効になる。

- フォント埋め込み：原則受理されるが、Kobo 端末のストレージ制限に配慮してサブセット化を推奨
- 縦書き：部分対応。リーダー実装により表示差異あり

## 8.5 honto・BookLive

国内ストアは概ね EPUB をそのまま受理する。Apple Books と同程度の互換性が期待できるが、独自の入稿フォーマット要件（書誌情報の XML 同梱など）があることが多いため、各ストアの最新ガイドラインを確認する。

## 8.6 入稿前チェックリスト

入稿前に最低限確認すべき項目を示す。

```
[ ] EPUBCheck で 0 errors を確認
[ ] 表紙画像が各ストアの要件を満たす
[ ] 書誌情報（タイトル、著者、出版者、ISBN）が正確
[ ] 章タイトルと目次が一致
[ ] 画像 alt がすべての画像に設定済み
[ ] 連絡先・コピーライト表記が奥付に記載
[ ] サンプル切り出し位置（特に Kindle なか見！検索）が冒頭の魅力的な箇所に来る
[ ] 主要 3 リーダー（Apple Books、Kindle Previewer、Thorium）で実機表示確認
```

今後、`@kappan/plugin-kdp-lint`、`@kappan/plugin-cover-validate`、入稿用 GitHub Actions、Kindle Previewer 統合が揃い、このチェックリストの大半が自動化される予定である。

## 8.7 商業流通の非目標

次の項目は Kappan のスコープ外である。

- **DRM 適用**：各ストアの責務
- **ISBN 取得・管理**：外部サービス連携で対応
- **著作権処理・出版契約周りの法務対応**
- **印税精算、販売チャネル横断管理**

これらは外部ツール・サービスとの連携で対応し、Kappan 本体は EPUB 成果物の品質保証と入稿適合に責務を集中する。
