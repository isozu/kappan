# 第9章 制約と今後の予定

本章では、本書が扱う範囲で「できないこと」を明示し、それぞれが今後どのように提供されるかを示す。

## 9.1 本書が扱う範囲

本書が前提とするビルドの達成基準は次の項目である。

1. CommonMark → EPUB 3.3 の生成
2. EPUBCheck 5.x エラーゼロ
3. 最小テーマ 1 つ（Mono）
4. schema.org アクセシビリティメタデータの自動付与
5. 画像 alt 属性の必須化

これらはいずれも満たされている。

## 9.2 記法の対応状況

本書の範囲で使える記法と、プラグインによって追加される記法を次に示す。

| 機能                           | 提供       | プラグイン                        |
| ------------------------------ | ---------- | --------------------------------- |
| ルビ・圏点・縦中横             | 対応済み   | `@kappan/remark-jp`               |
| shiki によるコードハイライト   | 対応済み   | `@kappan/remark-tech`             |
| KaTeX による数式               | 対応済み   | `@kappan/remark-tech`             |
| Mermaid ダイアグラム           | 対応済み   | `@kappan/remark-tech`             |
| 図表番号と相互参照             | 対応済み   | `@kappan/plugin-figure-numbering` |
| GFM 脚注                       | 対応済み   | コアに統合                        |
| 索引（読みがな順）             | 対応済み   | `@kappan/plugin-jp-index`         |
| 四字熟語・故事成語の表記整形   | 対応済み   | `@kappan/plugin-yojijukugo`       |
| 校正支援（てにをは・表記揺れ） | 今後の予定 | `@kappan/plugin-koseishi`         |
| 参考文献（BibTeX/CSL）         | 今後の予定 | コアに統合                        |

## 9.3 組版の対応状況

公式テーマは次の通り。

| テーマ         | 用途                         | 提供     |
| -------------- | ---------------------------- | -------- |
| Mono           | 装飾を最小化したベースライン | 対応済み |
| Saiun（彩雲）  | 技術書・実用書               | 対応済み |
| Sumi（墨）     | 小説・エッセイ（縦組み前提） | 対応済み |
| Kohaku（琥珀） | 論文・レポート               | 対応済み |
| Hibana（火花） | マニュアル・社内文書         | 対応済み |

縦組みには対応済みで、固定レイアウト書籍（漫画・絵本）は今後の予定である。

## 9.4 CLI の対応状況

提供される CLI コマンドは次の通り。

| コマンド                                    | 用途                                  |
| ------------------------------------------- | ------------------------------------- |
| `kappan build`                              | EPUB のビルド                         |
| `kappan init`                               | プロジェクト雛形の生成                |
| `kappan preview`                            | HMR 付きプレビューサーバ              |
| `kappan check`                              | リンク・alt・見出し階層の単独チェック |
| `kappan themes`                             | インストール済テーマ一覧と試し見      |
| `kappan plugin init/test/link/publish/list` | プラグイン開発支援                    |
| `kappan migrate review`                     | Re:VIEW からの一括変換                |

## 9.5 プラグイン API

`definePlugin()` ファクトリ関数と全フックが公開されており、サードパーティ作者がプラグインを書ける。公式プラグインは優先度の高いものから順に提供されている。

## 9.6 商業流通向け機能

各ストア向けの最適化機能は今後の予定である。

- KDP 入稿チェックリストの自動実行（`@kappan/plugin-kdp-lint`）
- 表紙画像の仕様検証（`@kappan/plugin-cover-validate`）
- 奥付の自動生成（`@kappan/plugin-okuduke`）
- Kindle Previewer 3 の自動統合
- Media Overlays 基本実装（Apple Books オーディオブック連動）

## 9.7 アクセシビリティ検証

EPUBCheck と内蔵 a11y チェック（alt 属性、見出し階層）に加え、**ACE by DAISY** による網羅的な検証が組み込まれている。商業流通を本格的に視野に入れる場合、ACE の検査は欠かせない。

## 9.8 公開 API の凍結

`@kappan/*` パッケージは公開 API を凍結したうえで npm 公開されている。semver を厳格に運用し、破壊的変更は事前に告知する。

## 9.9 今後の予定

今後の主な予定は次の通り。

- 校正支援・参考文献などの記法拡張
- 固定レイアウト書籍（漫画・絵本）対応
- 各ストア向け入稿リント
- LSP / エディタ統合
- Media Overlays の拡充
