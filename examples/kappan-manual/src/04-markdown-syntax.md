# 第4章 Markdown の書き方

本章では Kappan がコアでサポートする Markdown 記法を整理する。基本は CommonMark 0.31.2 と GitHub Flavored Markdown（GFM）に従う。

## 4.1 見出し

ATX 形式（`#` から始まる）と Setext 形式（下線型）の両方が使える。

```markdown
# 第1階層

## 第2階層

### 第3階層

# Setext 第1階層

## Setext 第2階層
```

第6階層（`######`）まで使えるが、深すぎる見出しは読者の認知負荷を上げるため、第4階層までで抑えることを推奨する。

## 4.2 段落と強調

段落は空行で区切る。同じ段落の途中で改行しても、出力上はスペースに変換される。強調は次のように記す。

```markdown
本文中で _斜体_ と **太字** と ~~打ち消し線~~ を組み合わせる。
両者を重ねれば **_太字斜体_** も使える。
```

## 4.3 リスト

順序なしリスト、順序付きリスト、タスクリストの三種が使える。

```markdown
- 順序なし
- 項目

1. 順序付き
2. 項目

- [x] 完了したタスク
- [ ] 未完了のタスク
```

リストは入れ子にできる。子項目はスペース2文字分のインデントで表現する。

## 4.4 コード

インラインコードはバッククォートで囲む。ブロック単位のコードはフェンス（バッククォート3つ）で囲み、言語を指定できる。

````markdown
インラインの `code` と、

```typescript
function greet(name: string): string {
  return `Hello, ${name}`;
}
```
````

のようなフェンスコードブロックが使える。

````

コア単体では言語指定があっても構文ハイライトはされず、`<pre><code class="language-typescript">` のクラスが付与されるだけである。テーマ側で着色する余地が残されている。実際の構文ハイライトは `@kappan/remark-tech`（shiki 経由）で行う。

## 4.5 引用

ブロック引用は行頭に `>` を置く。複数行や入れ子も可能である。

```markdown
> これは引用文である。
> 複数行にわたって書ける。
>
> > 入れ子の引用。
````

## 4.6 リンク

通常のリンク、タイトル付きリンク、参照スタイル、自動リンクの四種が使える。

```markdown
[Kappan のリポジトリ](https://example.com/kappan)

[公式サイト](https://example.com 'Kappan 公式')

[参照リンク][ref]

[ref]: https://example.com/ref '参照先のタイトル'

自動リンク：https://example.com も書ける（GFM）
```

## 4.7 画像と代替テキスト

画像は Markdown の標準記法で書く。`alt` 属性は必須で、省略するとビルドエラーになる。

```markdown
![図1：システム構成](images/architecture.png 'システム構成図')
```

画像パスは章ファイルからの相対パスで指定する。Kappan は EPUB 内の `images/` ディレクトリに画像を自動配置し、Markdown の参照を内部パスに書き換える。

装飾目的の画像（情報を持たない罫線や挿絵）の場合は HTML 直書きで `role="presentation"` を付ければ alt が空でも許容される。ただし HTML 埋め込みはデフォルトで禁止されているため、この用途には `unsafeHtml` の設定が必要になる。

## 4.8 テーブル

GFM 形式のテーブルが使える。列の整列はコロンの位置で指定する。

```markdown
| 機能   | 状態 |     備考 |
| :----- | :--: | -------: |
| 見出し |  ✓   |   左寄せ |
| リスト |  ✓   | 中央寄せ |
| コード |  ✓   |   右寄せ |
```

セル内には強調・インラインコード・リンクなど、ほとんどのインライン要素を入れられる。

## 4.9 水平線

水平線（テーマブレイク）はハイフン三つ以上、またはアスタリスク三つ以上で表現する。

```markdown
---

---
```

EPUB 出力では `<hr/>` 要素となり、テーマの CSS で意味段落の境界として描画される。

## 4.10 プラグインで有効化する記法

以下はコア単体では有効化されておらず、プラグインを追加して使う。

- **ルビ・圏点・縦中横**：日本語拡張記法（`@kappan/remark-jp`）
- **GFM 脚注（`[^id]`）**：コアに統合
- **数式（`$...$`）**：KaTeX 統合（`@kappan/remark-tech`）
- **Mermaid ダイアグラム**：`@kappan/remark-tech`
- **図表番号と相互参照（`[@fig:id]`）**：`@kappan/plugin-figure-numbering`
- **索引（`{!語!}`）**：`@kappan/plugin-jp-index`
- **HTML 埋め込み**：デフォルト禁止（`unsafeHtml` で許可制）
