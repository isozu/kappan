# 第1章 インライン記法 {#inline}

**太字** と *斜体* を組み合わせる。`const x = 1` はインラインコードである。

{活版|かっぱん}は近代日本の出版を支えた技術である。[Kappan]{.kw} はその名を継ぐ。

外部リンクは [公式サイト](https://example.com) のように書く。

脚注も使える[^note1]。脚注は本文の流れを妨げずに補足を添えられる。

[^note1]: 脚注は本文側で参照を置き、章末で定義をまとめる。
