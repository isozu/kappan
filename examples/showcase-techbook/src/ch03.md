# 第3章 数式と脚注 {#ch03}

技術書では、文章だけでは{冗長|じょうちょう}になる関係を数式で簡潔に表したい場面が
ある。本章では KaTeX による数式組版と、補足を本文から切り離す脚注を扱う。

## 3.1 ブロック数式 {#sec:block-math}

ブロック数式は `$$ ... $$` で囲む。直後の段落に `{#eq:id}` を置くと、
`figureNumbering` が式番号を採番し、本文から `[@eq:id]` で参照できる。

たとえば、ビルド全体の計算量を考える。章数を $n$、1 章あたりの平均ノード数を $m$ と
おくと、変換コストはおおむね次のように見積もれる。

$$T(n, m) = \sum_{i=1}^{n} (m_i \log m_i)$$

{#eq:build-cost}[@eq:build-cost]のように、各章の変換は概ね $m \log m$ で、章の総和に
なる。{並列化|へいれつか}が効くのは章単位の独立性が高いためである[^ch3-parallel]。

## 3.2 インライン数式

インライン数式は `$ ... $` で囲む。文章の流れを切らずに記号を埋め込める。

たとえば「ハイライト済みノード数 $h$ がコード片の総数 $c$ に比例する」と書けば、
$h = O(c)$ という関係が一目で伝わる。索引語 {!計算量|けいさんりょう!} の議論では、
こうした記号の混在が読みやすさを大きく左右する。

本章で使う記号 {#tbl:math-symbols}

| 記号  | 意味             |
| ----- | ---------------- |
| $n$   | 章数             |
| $m$   | 1 章のノード数   |
| $T$   | 変換コスト       |

[@tbl:math-symbols]に記号の意味をまとめた。

## 3.3 数式とアクセシビリティ

Kappan の `katexMath` は既定で [MathML]{.kw} を出力する。MathML は EPUB 3 の
標準であり、スクリーンリーダーが数式を読み上げられる。見た目の互換性を
優先したい場合は、HTML 描画と MathML を併用する設定も選べる。

出力形式の切り替え {#lst:katex-output}

```typescript
// 既定は MathML 出力（アクセシブル・EPUB 標準）
katexMath();

// 見た目互換を優先するなら HTML+MathML 併用
katexMath({ output: 'htmlAndMathml' });
```

[@lst:katex-output]のように、出力形式は一行で切り替えられる。
本書はアクセシビリティを優先し、既定の MathML 出力を採用している。

> 数式は「読める」だけでなく「読み上げられる」べきである。
> MathML を既定にするのは、その思想の表れだ。
>

## 3.4 脚注の使いどころ

脚注は、本筋を妨げない補足に向く。出典、細かい但し書き、{余談|よだん}などである。
本文では `[^id]`、定義は末尾に `[^id]:` と書く[^ch3-style]。

脚注を入れすぎると視線が往復して読みにくくなる。1 段落に 1 つまでを目安に、
本当に必要な補足だけを脚注へ落とすとよい。

[^ch3-parallel]: 章単位の並列ビルドは将来の検討事項である。本書のような
    小規模な書籍では逐次ビルドでも十分高速で、体感差はほとんどない。

[^ch3-style]: 脚注番号の体裁はテーマが決める。彩雲テーマではアクセント色
    （既定 `#1f3a5f`）の上付き番号として表示され、本文との対応が分かりやすい。
