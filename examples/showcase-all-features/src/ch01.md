# 第1章 図表とコード {#ch01}

本章では、技術書の骨格となる図・表・コード・節の自動採番と相互参照を一通り見せる。
番号は章内で自動採番され、参照はハイパーリンクになる。

## 図と相互参照 {#sec:figure}

![Kappan のビルドパイプライン](../assets/images/diagram.png){#fig:pipeline}

[@fig:pipeline]に示すとおり、Markdown は AST を経て EPUB へ変換される。
節そのものも [@sec:figure] のように参照できる。

## コードと表 {#sec:code}

コードは shiki でビルド時にハイライトされ、リーダー側の CSS 制限を受けない。

ビルドの最小呼び出し {#lst:build}

```typescript
import { buildBook, loadConfig } from '@kappan/core';

const { config, configDir } = await loadConfig('kappan.config.ts');
await buildBook({ config, configDir, outputPath: 'dist/book.epub' });
```

[@lst:build]のとおり、著者が触れる API は小さい。表にも番号が付く。

主要プラグインの段階 {#tbl:plugins}

| プラグイン | 介入段階 |
| ---------- | -------- |
| ruby / kenten | hast |
| figure-numbering | mdast |
| shiki | hast |

[@tbl:plugins]のように、プラグインは「どの段階に介入するか」で役割が決まる。
詳しい採番規則は [@chap:ch02] でも引き続き使う。
