# 第3章 囲み記事とコラム {#ch03}

本章では、本筋を補強する囲み記事（admonition）と、少し離れた読み物であるコラムを見せる。
どちらも `remark-directive`（`:::`）で書く。

## 囲み記事 {#sec:admonition}

:::note
注記。補足を本文から少し浮かせて示す。
:::

:::tip
ヒント。緑系で表示される（彩雲テーマ）。
:::

:::warning[互換性の注意]
警告。タイトル付き。古いリーダーでは MathML が表示できない。
:::

## コラム {#sec:column}

コラムは目次にも載り、本文から参照できる。

:::column[なぜ「活版」なのか]{#col:why-kappan}
活版印刷は、文字を一つひとつ組んで版を作る技術だった。Kappan も、記法という小さな部品を
組み合わせて一冊を組み上げる。名前はその精神への敬意である。
:::

このツール名の由来は [@col:why-kappan] で触れた。第1章の図（[@fig:ch01/pipeline]）と
合わせて読むと、設計思想が見えてくるはずだ。
