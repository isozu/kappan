# 第2章 数式・脚注・索引 {#ch02}

本章では、学術・技術書で欠かせない数式・脚注・巻末索引を見せる。

## 数式 {#sec:math}

インライン数式は $E = mc^2$ のように本文に溶け込む。ディスプレイ数式は番号を振れる。

$$
\int_{0}^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}
$$

{#eq:gauss}

[@eq:gauss]はガウス積分である。既定出力は MathML（EPUB 3 ネイティブ・アクセシブル）。
