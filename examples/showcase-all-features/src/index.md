# はじめに

本書は **Kappan** の主要記法を一冊に詰め込んだ「全部入り」ショーケースである。
Markdown で原稿を書き、1 コマンドで EPUB 3.3 を生成する——その過程で、日本語書籍に
必要な組版要素がどこまで自然に表現できるかを、実際の誌面で確かめてほしい。

## この章で確かめる：ルビ・圏点・基本記法

ルビはパイプ形式 {活版|かっぱん}印刷でも、属性形式の [校正]{ruby="こうせい"} でも振れる。
出力はどちらも同じ `<ruby>` で、両者は混在できる。たとえば
{校正刷|こうせいずり}と [試刷]{ruby="しずり"} を一文に並べても順序どおり処理される。

ここが[重要]{.kenten}な点だ——著者は記法を覚えるより、内容に集中できる。

CommonMark / GFM の基本もそのまま使える。

- 箇条書きと **強調**・*斜体*・`インラインコード`
- [リンク](https://github.com/isozu/kappan)
- 取り消し線 ~~旧版~~

> 引用ブロックもそのまま通る。

| 記法 | 形式 |
| ---- | ---- |
| ルビ（パイプ） | `{活版\|かっぱん}` |
| ルビ（属性） | `[校正]{ruby="こうせい"}` |
| 圏点 | `[重要]{.kenten}` |
