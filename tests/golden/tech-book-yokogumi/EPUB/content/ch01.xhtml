第1章 ネットワーク基礎

ネットワークは現代の分散ぶんさんシステムの土台である。本章では、TCP/IP の 階層構造かいそうこうぞうと そこに乗る代表的なプロトコルについて、横組み技術書らしい密度で解説する。

1.1 OSI 参照モデル

OSI参照モデルは 7 階層からなる。各階層は独立した責務を持ち、上位層は下位層の 詳細を意識せずに通信できる。これを 抽象化 と呼び、現代のソフトウェア設計に おける最重要原則のひとつだ。

図1.1に示すように、各層は明確な役割を持つ。

階層ごとの役割

  1. 物理層：電気信号やパルスの物理的な伝送
  2. データリンク層：隣接ノード間のフレーム転送
  3. ネットワーク層：ルーティングと到達性
  4. トランスポート層：信頼性とフロー制御
  5. セッション層：通信セッションの管理
  6. プレゼンテーション層：データ表現の変換
  7. アプリケーション層：エンドユーザー機能

1.2 IP アドレスとサブネット

IPv4 アドレスは 32 ビット、IPv6 アドレスは 128 ビットで表現される。サブネットマスクは ネットワーク部とホスト部を区切るためのビットマスクである1。

プロトコル アドレス長 表記例
IPv4 32 bit 192.0.2.1/24
IPv6 128 bit 2001:db8::1/64

上表（表1.1）に示した通り、IPv4 と IPv6 はアドレス空間に大きな差がある。

1.3 TCP と UDP

トランスポート層の代表的なプロトコルは TCP と UDP である。

// TCP は信頼性のあるストリーム指向
const socket = net.createConnection({ port: 8080 });
socket.on('data', (chunk) => {
  console.log('received', chunk.length, 'bytes');
});

// UDP はコネクションレスでメッセージ指向
const udp = dgram.createSocket('udp4');
udp.send(Buffer.from('hello'), 53, 'dns.example');

上記サンプル（リスト1.1）からわかるように、API レベルでも両者の設計思想は異なる。

TCP は信頼性、UDP は速度。アプリケーション要件に合わせて選ぶ。
