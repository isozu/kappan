# 縦組み EPUB を実機リーダーで目視確認する

Kappan は縦組み（`writingMode: 'vertical-rl'`）の構造的・仕様的な正しさを CI で自動保証する（Chromium レイアウト検証 + EPUBCheck + ACE + golden）。ただし **実フォントでの最終的な組版品質** は EPUB リーダー実機でしか確認できない。本書は商業出版（特に Kindle Unlimited 縦書き小説）の前に著者が目視すべき項目をまとめる。

## 自動保証される範囲（CI、確認不要）

- `<html dir="rtl">` + `<body class="kappan-vertical-rl">` + OPF `page-progression-direction="rtl"` の出力
- Chromium（Thorium 近似）での縦右→左フロー、ルビ右側、圏点右側、縦中横正立、コードブロック横組み内包
- EPUBCheck 0 errors / ACE アクセシビリティ違反なし

## 実機で目視すべき項目（ユーザー領域）

縦組みでビルドした `.epub` を各リーダーで開き、以下を確認する。

```bash
pnpm kappan build --config /path/to/novel/kappan.config.ts --validate
# 生成された dist/*.epub を実機で開く
```

### 最低互換ターゲット

| 項目       | Apple Books | Kindle | Kobo | Thorium |
| ---------- | ----------- | ------ | ---- | ------- |
| 縦書き本文 | ✅          | ✅     | ⚠    | ⚠       |
| ルビ位置   | ✅          | ⚠      | ⚠    | ⚠       |
| 圏点位置   | ✅          | ⚠      | ❌   | ⚠       |
| 縦中横     | ✅          | ⚠      | ⚠    | ✅      |

`⚠`/`❌` はリーダー側の CSS 解釈限界。`@kappan/plugin-reader-shim` が prefix 併記で吸収を試みるが、リーダーのアップデート次第。

### チェックリスト

1. **本文の流れ**：縦書きで右から左へ流れ、行が下から上でなく上から下に進む
2. **ルビ**：親文字の**右側**に出る（左側に出ていたらリーダーの ruby-position 非対応）。ルビが本文の行間を不必要に広げていないか
3. **圏点（傍点）**：文字の**右側**に出る（縦書きの正しい位置）
4. **句読点の行頭禁則**：「。」「、」が行頭に来ていないか（リーダー差異に関係なく機能するのが Kappan の目標）
5. **縦中横**：2 桁の半角数字（例「12」）が正立して横に組まれ、4 桁の年号（例「1923」）は縦に流れているか
6. **連続約物**：ダーシ「――」と三点リーダ「……」が途中で改行されず、字間も空いていないか
7. **章扉**：各章が新ページから始まり、章タイトルの前後に十分な余白があるか
8. **コードブロック**：縦組み本文中でもコードは横組みで表示されているか
9. **会話文と地の文**：地の文は 1 字下げ、会話文（行頭カギ括弧）は 1 字下げなし

### 既知の限界

- **柱（ページ上部の書名・章名）** と **ノンブル（ページ番号）** はリフロー EPUB ではリーダーがページを決めるため出力しない。固定ページが必要な場合は今後の固定レイアウト書籍対応を待つ
- Kobo / Thorium は縦組み CSS のサポートが限定的（リーダー側の問題で、Kappan の出力は仕様準拠）

### 問題を見つけたら

- 構造的な問題（dir/class/OPF が出ていない、EPUBCheck エラー）は Kappan のバグ。GitHub Issue へ
- リーダー固有の表示崩れは `reader-shim` のプロファイル調整で改善できる場合がある。`kappan build --simulate-reader kindle` 等で該当プロファイルの CSS を当てて再確認
